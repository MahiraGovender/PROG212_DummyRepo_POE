| HTTP Method | Route | Description | Role Required | Request Body (if any) | Expected Response |
|---|---|---|---|---|---|
| **POST** | `/api/auth/register` | Registers a new user account and creates the appropriate Organiser or Participant profile based on the selected role. | None (public) | `firstName`, `lastName`, `email`, `password`, `role`, plus `dateOfBirth`, `emergencyContact` for Participant or `contactEmail`, `phoneNumber`, `organisation` for Organiser | **201 Created** – account and profile created. **400 Bad Request** – invalid data. **409 Conflict** – email already exists. |
| **POST** | `/api/auth/login` | Authenticates a registered user and returns authentication details and their role. | None (public) | `email`, `password` | **200 OK** – login successful with user ID, role and token. **401 Unauthorized** – invalid email or password. |
| **GET** | `/api/profile` | Retrieves the currently authenticated user's profile information. | Any (logged in) | None | **200 OK** – user's account and role-specific profile information. **401 Unauthorized** – user is not authenticated. **404 Not Found** – profile does not exist. |
| **PUT** | `/api/profile` | Updates the currently authenticated user's profile information. | Any (logged in) | Common account fields and role-specific profile fields such as `firstName`, `lastName`, `email`, `dateOfBirth`, `emergencyContact`, `contactEmail`, `phoneNumber`, `organisation` | **200 OK** – updated profile. **400 Bad Request** – invalid data. **401 Unauthorized** – not authenticated. **409 Conflict** – email already in use. |
| **GET** | `/api/events` | Retrieves all available events so users can browse upcoming events. | None (public) | None | **200 OK** – list of events including name, description, date, location, distance/category information and event type. |
| **GET** | `/api/events/{eventId}` | Retrieves the details of a specific event. | None (public) | None | **200 OK** – event details. **404 Not Found** – event does not exist. |
| **POST** | `/api/events` | Creates a new event belonging to the authenticated organiser. | Organiser only | `eventName`, `description`, `eventDate`, `location`, `eventTypeId` | **201 Created** – event created. **400 Bad Request** – invalid data. **401 Unauthorized** – not logged in. **403 Forbidden** – user is not an organiser. |
| **PUT** | `/api/events/{eventId}` | Updates an event owned by the authenticated organiser. | Organiser only | `eventName`, `description`, `eventDate`, `location`, `eventTypeId` | **200 OK** – updated event. **400 Bad Request** – invalid data. **403 Forbidden** – organiser does not own the event. **404 Not Found** – event does not exist. |
| **DELETE** | `/api/events/{eventId}` | Deletes an event owned by the authenticated organiser. | Organiser only | None | **204 No Content** – event deleted. **403 Forbidden** – organiser does not own the event. **404 Not Found** – event does not exist. |
| **GET** | `/api/event-types` | Retrieves the available event types such as Road Running, Walking and Cycling. | None (public) | None | **200 OK** – list of event types. |
| **GET** | `/api/events/{eventId}/categories` | Retrieves all categories available for a specific event. | None (public) | None | **200 OK** – list of categories including category name, distance, entry fee, start time and participant limit. **404 Not Found** – event does not exist. |
| **POST** | `/api/events/{eventId}/categories` | Creates a new age or distance category for an event owned by the authenticated organiser. | Organiser only | `categoryName`, `distance`, `entryFee`, `startTime`, `maximumParticipants` | **201 Created** – category created. **400 Bad Request** – invalid data. **403 Forbidden** – organiser does not own the event. **404 Not Found** – event does not exist. |
| **PUT** | `/api/events/{eventId}/categories/{categoryId}` | Updates an existing category belonging to an event owned by the authenticated organiser. | Organiser only | `categoryName`, `distance`, `entryFee`, `startTime`, `maximumParticipants` | **200 OK** – updated category. **400 Bad Request** – invalid data. **403 Forbidden** – organiser does not own the event. **404 Not Found** – category/event does not exist. |
| **DELETE** | `/api/events/{eventId}/categories/{categoryId}` | Deletes a category from an event owned by the authenticated organiser. | Organiser only | None | **204 No Content** – category deleted. **403 Forbidden** – organiser does not own the event. **404 Not Found** – category/event does not exist. |
| **POST** | `/api/events/{eventId}/enrolments` | Creates one enrolment for the authenticated participant and associates it with one or more selected event categories. | Participant only | `categoryIds`: `[1, 2]` | **201 Created** – enrolment created with selected categories. **400 Bad Request** – invalid category selection. **401 Unauthorized** – not authenticated. **403 Forbidden** – user is not a participant. **409 Conflict** – participant is already enrolled in the event. |
| **GET** | `/api/events/{eventId}/enrolments` | Retrieves all participant enrolments for an event managed by the authenticated organiser. | Organiser only | None | **200 OK** – list of enrolments including participant information and selected categories. **403 Forbidden** – organiser does not own the event. **404 Not Found** – event does not exist. |
| **GET** | `/api/enrolments/{enrolmentId}` | Retrieves the authenticated participant's enrolment and its selected categories. | Participant only | None | **200 OK** – enrolment details and selected categories. **403 Forbidden** – enrolment does not belong to the participant. **404 Not Found** – enrolment does not exist. |
| **DELETE** | `/api/enrolments/{enrolmentId}` | Cancels an enrolment belonging to the authenticated participant. | Participant only | None | **204 No Content** – enrolment cancelled/deleted. **403 Forbidden** – enrolment does not belong to participant. **404 Not Found** – enrolment does not exist. |
| **POST** | `/api/enrolments/{enrolmentId}/categories` | Adds an additional category to an existing participant enrolment, allowing the participant to select multiple categories within the same event enrolment. | Participant only | `eventCategoryId` | **201 Created** – category added to enrolment. **400 Bad Request** – invalid category. **403 Forbidden** – enrolment does not belong to participant. **409 Conflict** – category already selected. |
| **DELETE** | `/api/enrolments/{enrolmentId}/categories/{categoryId}` | Removes a selected category from an existing participant enrolment. | Participant only | None | **204 No Content** – category removed. **403 Forbidden** – enrolment does not belong to participant. **404 Not Found** – category/enrolment does not exist. |
| **POST** | `/api/enrolments/{enrolmentId}/categories/{enrolmentCategoryId}/result` | Records a participant's result for a selected category after the event, including finish time, finishing position and result status. | Organiser only | `finishTime`, `position`, `resultStatus` | **201 Created** – result recorded. **400 Bad Request** – invalid result data. **403 Forbidden** – organiser does not own the related event. **404 Not Found** – enrolment/category does not exist. **409 Conflict** – result already exists. |
| **PUT** | `/api/results/{resultId}` | Updates a previously recorded participant result. | Organiser only | `finishTime`, `position`, `resultStatus` | **200 OK** – updated result. **400 Bad Request** – invalid data. **403 Forbidden** – organiser does not own the related event. **404 Not Found** – result does not exist. |
| **GET** | `/api/results/me` | Retrieves all results belonging to the currently authenticated participant. | Participant only | None | **200 OK** – list of the participant's results including event, category, finish time, position and status. **401 Unauthorized** – not authenticated. |
| **GET** | `/api/events/{eventId}/results` | Retrieves results for participants in an event managed by the authenticated organiser. | Organiser only | None | **200 OK** – list of event results. **403 Forbidden** – organiser does not own the event. **404 Not Found** – event does not exist. |
